Design notes · round 1

Editorial meets instrument

Source of truthTokens, mock data and copy from DISTILL_DESIGN_BRIEF.md. Every number is derived from one dataset: 3,214 items, 14 themes, 6 opportunities, 41s, $1.87, 1.9M / 210K tokens, 78% cache, 91% precision. AssumptionsAt 00:24 the agent has processed 1,847 items and found 11 raw themes (8 taxonomy labels + 3 off-taxonomy labels that Cluster later merges: timer bugs, watch disconnects, too expensive). Stages: Ingest 0–2s · Extract 2–30s · Cluster 30–36s · Rank 36–38s · Brief 38–41s. "Other" counts as theme 14 and is drawn hollow so it never dominates the map. ReasoningMidnight everywhere, ember as the one accent. Cards sit one step lighter than the page; the live run sits one step deeper and is the only place with continuous motion. The evidence quote is one component with one style string, reused verbatim in the stream, the drawer, the opportunity page and the sheet; only the paragraph colour around it flips on the dark instrument. Stream pacing3,214 items in 28s is 115 items/s, unreadable as rows. The stream shows one representative row per batch of 20 (about 4 rows/s), labelled as such, so the feed is fast but legible. Three takes1a Constellation: packed nodes, glow, pulse rings, nodes drift together on merge. 1b Spectrum: a live-sorted bar readout with a tick grid, rows swap places as counts change. 1c Radar: severity rings, angle per theme, a slow sweep; opportunities are whatever sits large near the centre.
